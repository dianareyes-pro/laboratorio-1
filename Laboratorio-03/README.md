##  Descripción
Evolución del gestor de inventarios hacia el paradigma de Programación Orientada a Objetos (POO). Se implementan clases, encapsulamiento, propiedades (`@property`), validaciones de negocio y modularización de componentes.

---

## Estructura del Módulo
- `producto.py`: Clase `Producto` con atributos protegidos, métodos de cálculo y validadores de negocio.
- `inventario.py`: Clase `Inventario` que gestiona la colección de objetos y operaciones CRUD.
- `main.py`: Menú interactivo de consola para la gestión del sistema.
